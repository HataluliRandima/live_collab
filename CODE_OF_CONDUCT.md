# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. All contributors and maintainers are expected to follow it
in every project space: issues, pull requests, discussions and any other channel.

## Reporting

Report unacceptable behaviour privately to the maintainers through GitHub
([open a private security advisory](https://github.com/HataluliRandima/live_collab/security/advisories/new)
if you need a private channel, and say that it is a conduct report). Reports are
handled confidentially. Maintainers will act according to the enforcement
guidelines of the Contributor Covenant.
